# Standalone MOSS diagnostic source templates

This source-only snapshot contains unexecuted portable templates for one bounded,
standalone transcript-quality diagnostic using MOSS. It contains no audio, model
weights, installed runtime, database, transcript, execution record or local config.

## Historical result and evidence limits

One private standalone official MOSS call completed in 112.2235 seconds. Sampled
caller-plus-owned-process peak RSS was 1,606,160,384 bytes. The model produced
10 segments with 4 local speaker tags; 579 raw output bytes were retained privately.
The original child was positively waited and reaped, with confirmed cleanup of
observed owned processes. This does not close historical unknown process owners.

That result is a standalone diagnostic only. The API/CellStore path failed and
remains unqualified. Accuracy, timestamps, real speaker identity, end-of-sequence
completion and generated-token count remain unqualified. Local speaker tags are
model labels, not verified people. No raw output is published. These historical
observations do not qualify the substituted public templates.

## Files and dependencies

- standalone.py.in: bounded process supervisor and diagnostic entry template.
- test_standalone.py.in: eight-case model-free helper and source-contract suite.
- LOCAL_CONFIGURATION_FIELDS.json: complete typed substitution catalog.
- PUBLIC_MANIFEST.json: snapshot inventory, not a runtime source manifest.

Compatible external product modules are required: MossController, OwnedDriver,
CandidateGuard, moss_handy_runner.py, SourceSupport, qwen_candidate_runner and
retained-output accounting. The templates preserve Python 3.12, psutil 7.2.2,
the official MOSS Q8_0 model filename and native-library layout. Dependencies
are not bundled or downloaded by this snapshot.

## Local materialization

Generate every @GENERATED_NAME@ value from selected local files and paths.
Use canonical paths with no symlink aliases and consistent workspace-relative
roots. Hash exact local bytes; never use placeholders as digests. Integer fields
are int(token) expressions requiring actual integer values. Refuse unresolved or
undeclared tokens before any target execution.

Write generated files as standalone.py and test_standalone.py. The local four-file
packet also requires README.md and a new SOURCE_MANIFEST.json matching the source
schema and exact generated bytes. Keep its 32/12/4/8 KiB individual caps, 56 KiB
logical total and 80 KiB charged source limit. The public manifest cannot satisfy
that runtime schema. This rewritten documentation is separate from historical
source-byte restoration.

Selected support stays fixed at frames [8000,328000), 16000 Hz mono PCM16LE:
320000 samples, 640000 bytes and the matching float32LE digest. Local integrity
metadata binds the source manifest, model-free checks, source validation,
model/native descriptors and fixed limits. Descriptor order is device, inode,
mode, link count, bytes, mtime_ns, ctime_ns. Substitution is not validation.

## Process and resource contracts

The supervisor permits one child and one possibly started inference attempt,
without retry. Its absolute bound is 420 seconds: setup at most 60, compute at
most 300 within the original 360-second work endpoint, and cleanup at most 60
within the absolute endpoint. Unused phase time cannot enlarge a later maximum.
CPU affinity is 0 and 1, nice is 19 and address space is capped at 8 GiB. Preserve
all sampled RSS, reserve, disk, output namespace and size checks. Sampled RSS
is not a kernel memory quota. Context is 855 with a 512-token reservation.

Retain raw bytes before parsing. Keep original process handles and current owned
identities; cleanup covers observed owned descendants only. Fresh outputs are
exclusive and previous runs are not adopted. No HTTP service, API request,
SQLite access, primary analysis, native diarization or download belongs to this
standalone path. The focused suite creates no child, socket or database; it does
not qualify inference. Neither public template was executed for this checkpoint.
