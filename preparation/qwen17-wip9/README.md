## Recovery limits

These are unexecuted, non-runnable recovery templates, not a standalone installation or test package. Their .template suffix and deliberately invalid local pin placeholders prevent them from serving as approved execution inputs. Filling placeholders or adapting paths requires a new reviewed environment, complete source/input pinning, resource admission and fresh qualification. Do not replace integrity checks with permissive defaults.

The original layout references remain to show dependencies. The environment-specific launchers, frozen specifications, private settings, manifests, receipts, logs, evidence lineage and absolute host paths are excluded. Templates need those independently reviewed dependencies before any execution can be considered; this checkpoint does not reconstruct them or grant execution authority.

No credentials, live environment/proxy values, actual run identifiers, audio, transcripts, models, wheels or installed runtime payloads are included. Import compatibility alone does not establish model-load feasibility, decoding correctness, transcription quality, timing quality or production readiness.
