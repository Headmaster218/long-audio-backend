## Preparing a target configuration

Replace every @GENERATED_NAME@ token consistently from a fresh target configuration. Paths must be canonical and match their declared absolute or workspace-relative type. Relative category roots, packet paths and asset paths must agree across the configuration and source templates. A token is never a filesystem path or a usable digest by itself.

Integer tokens are strings in the JSON template and int(...) expressions in Python templates. Generate real integer JSON values and decimal Python integer literals. SHA-256 tokens require the exact bytes of the corresponding target artifact; do not reuse a sample digest or infer success from a path.

Generate the closed runtime packet inventory, exact source pins and manifest expected by the supervisor. Its 15-file packet schema is distinct from this 17-file template snapshot: the supervisor and this catalog are outside that runtime packet. Preserve all namespace and cap checks. Independently validate the compatible external guard and census dependencies, then repeat model-free and split checks against the generated bytes before considering inference.

Public product/model identities remain pinned. Operational records, executable/source identities, decoder version-output identities, session identifiers and the input WAV identity must be generated for the target. Synthetic parser fixture dictionaries are only test data, with generated identity placeholders. They cannot qualify an execution.

The candidate requires two original positive commits and a same-response natural seam-crossing overlap. If that overlap is absent, qualification remains incomplete. The candidate limits remain two CPU cores, 4 GiB aggregate sampled RSS, 8 GiB address space, 544 MiB incremental disk and 1800 seconds. RSS sampling is not a hard quota. The preparation supervisor has its own smaller finite bounds. Preserve phase deadlines, exclusive output namespaces, original-handle waits, identity-safe cleanup and final source hashing. Success remains provisional until cleanup and posthash complete.
