# Optional native diarization setup

> Public-source edition: historical model measurements below were imported from prior development documentation, not rerun for this Git import. Full raw evaluation records and media are intentionally excluded. See [public test scope](../TEST_STATUS.md).


The current default remains pyannote. The native alternative is CPU-validated,
but neither its quality nor the complete project is declared accepted.

## Install and verify

With the backend Python environment active:

```sh
python scripts/setup_native_diarization.py
python scripts/setup_native_diarization.py --verify-only
```

The installer pins the official NeMo-Speech.cpp0.2.0 runtime and
Nemotron-3-Diarization Q8 model by exact size and SHA256. It retains runtime
notices, verifies the bundled OpenMDW-1.1 model license, and prints the local
Settings fields. No online inference/API is used. Downloads are required once.
CPU packages support x86_64 Linux and Windows. Windows archive download,
hash verification and safe extraction were tested on Linux; Windows execution
was not tested.

Runtime license: Apache-2.0 plus bundled third-party notices.
Model license: OpenMDW-1.1; keep model origin and license notices when redistributing.
- https://github.com/NVIDIA/NeMo-Speech.cpp/releases/tag/v0.2.0
- https://huggingface.co/nvidia/Nemotron-3-Diarization
- https://raw.githubusercontent.com/OpenMDW/OpenMDW/main/1.1/LICENSE.OpenMDW-1.1

`--platform windows-x86_64` prepares the Windows package from another host.
Do not load its DLL on Linux. Paths printed on a preparation host must be
regenerated by the installer after migration.

## Vulkan qualification

Upstream publishes Linux/Windows Vulkan packages, pinned in
native-runtime-manifest.json. `--runtime vulkan` may prepare one, but the current
provider explicitly requests CPU (`gpu=-1`). Merely choosing a Vulkan-enabled
library does not enable or validate GPU processing. A future explicit device
adapter and real target-hardware test are required. Current Whisper.cpp ASR has
a separate Vulkan path; do not confuse the two backends.

## Timing and capacity

The measured native preset consumes21.12-second batches with80ms right context;
its conservative stable-output frontier reserves another2seconds. Continuous
uploads can therefore wait for more than the ordinary2-second ASR tail. Only
actual stream end calls native finish. The worker uses300-second epochs plus
bounded replay context and a360-second provider hard cap. Local slots are
qualified by epoch; ERes voice evidence handles global identity separately.
Maximum8 local speaker slots include replay context. More people over a long
recording can be encountered across epochs, but more than8 in one epoch is not
validated and may merge voices. Raw simultaneous turns are preserved.

See reports/nemotron-trial/README.md and the native integration reports for
measured DER, sparse-case failure, lifecycle tests and CPU memory. Model-card
metrics use a different protocol and are not our observed accuracy.
