# dev33：显式、可追溯的 10 ms 末端策略

版本：`0.2.0rc3.dev33`。本版在 dev32 上增加一个前瞻性的结果时间戳策略。默认模型开关、任务与清理截止时间、资源上限、数据库表结构、支持区间和覆盖归属不变；不重新运行模型，不改写或重新解析历史结果。此前保留的实际运行失败及其未知调用计数仍属于原版本范围。

## 唯一可调整的边界

新投影标记 `timestamp_policy=support-end-intersection-10ms-v1`。允许条件是原始数值严格满足 `0 ≤ start < support_end < end ≤ support_end + 0.010`，且投影为整数采样帧后的交集非空。支持时长由既有 16 kHz 支持帧计算，终点精确落在支持末端帧。起点不向前扩展，支持坐标、接缝/普通窗口归属、文本内容、排序和模型局部说话人标签不改变。

10 ms 是显式的应用容差，不声称模型以 10 ms 量化，也不证明端点或转写正确。更大越界、负值、逆序、相等端点、非有限值、原格式不匹配以及帧投影后为空的调整候选继续拒绝。原始模型文本和已有无时间文本保留规则不变；该策略不是通用修复或跨短语单调性校正。

## 精确计算与有限工作量

每个数值 token 在 Decimal 转换及保留之前最多 128 个字符；超过上限的有限候选明确标记容量拒绝。沿用原始文本 128 KiB 和最多 256 个短语的限制，精确 Decimal 路径最多处理 65,536 个数值字符；保留的非有限或无效原始 token 仍受不变的原始文本上限约束。现有语法只接受无符号普通十进制，不增加指数或其它语法。

支持时长和 10 ms 上界从整数帧直接构造精确 Decimal，比较不依赖默认 Decimal context 的舍入。起点到帧的转换使用与 token 上限匹配的固定有限精度；若向内取整后已到达末端，则拒绝。展示终点与 transcript 的终止帧均使用原支持末端；没有增加帧原点或改变支持所有权。

## 原始证据和完整性

每个调整短语必须带完整的 `timestamp_adjustment`：策略、固定原因 `support_end_intersection_within_10ms`、原始起止字符串、原始有限数值、支持 ID、绝对支持末端帧、相对末端帧以及 `timestamp_quality=model_generated_unverified`。消费者重新验证记录的字段、精确类型、原始条件和支持绑定，不只相信一个调整标志。

新投影还必须提供 `timestamp_adjusted_phrase_count`，类型为整数而非布尔，范围 0 至 256，等于实际保留的调整记录数。缺失计数、数量不符、删掉整条调整记录、未知策略或不完整记录均拒绝；策略字段被移除但计数/调整记录残留时，也不能降级为旧格式。没有这些新字段的真实旧结果保持原严格解释。

沿用诊断 65,536 字节及结果 229,376 字节的既有上限。调整证据是必需内容，不能为适应上限仅删掉证据却保留调整短语。触发整体诊断/结果拒绝时，短语和调整计数一起清空并保留原容量失败语义。原始证据不是可任意省略的附加诊断。

## Transcript 与说话人兼容性

当前 transcript 合约前进为 `current-unified-transcript-v3`，策略摘要包括严格旧时间和完整验证的新策略。既有 ordinary/audit 游标在新策略下返回冲突，需要从无游标请求重新开始。结果存档、proof 和数据库历史字节不重写；选择仍依赖完整支持区间和既有覆盖路径，不以调整后的短语扩大来源范围。

调整短语不生成 speaker probe 音频裁剪，使用固定的 `timestamp_adjusted_unverified` 无裁剪状态。它的向外帧占用区间仍阻止其它短语，包括相同局部标签的短语，错误地把同时说话当作干净音频。新批次和 projection 摘要绑定输入时间策略；既有 speaker 评分/选择策略摘要不被全局重写，旧批次与历史继续验证和读取。

## 模型无关验证与限制

专项 79 个用例通过。覆盖精确 10 ms 内外边界、长 token、低精度 Decimal context、帧为空、完整原始记录/支持绑定、计数类型和缺失、部分字段剥离、结果容量以及说话人占用阻挡。测试使用合成时间字符串、PCM 和 proof，真实新建 SQLite 的保存/重开，以及禁用模型的 transcript HTTP 路径。

相关回归分为三组：adapter/拒绝诊断 56 个与 10 个子测试；speaker 选择与存储 60 个；transcript HTTP、索引及投影 130 个。总计另 246 个通过，无排除或失败。两个旧拒绝示例及对应的期望数值，仅把微小越界改到超过 10 ms，其原断言保留；旧边界另在新用例中验证为带证据的调整。

四个原始测试进程均正向完成，没有资源违规，临时 fixture 已清理。各组限定 CPU 3、nice 19、120 秒、pytest 进程抽样 RSS 256 MiB、地址空间 1 GiB、临时 fixture 16 MiB；抽样 RSS 不是全部后代的强制聚合峰值。这些测试不提供声学、转写、时间戳或说话人准确率，也没有将新策略用于此前的实际模型结果。历史质量和持久化资格仍以各自版本的事实记录为准。
