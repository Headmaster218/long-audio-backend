# Frozen selection and metric contract

Target: 64 complete annotated utterances, 8 per meeting, 4 quiet + 4 ordinary. Report shortfall rather than change rules. Source is native channel index 0 of 8-channel PCM16 16kHz array. Exact original channel sample bytes, no processing, used identically by both later arms.

Boundary policy: use Decimal on original timestamp lexemes, never author-code centisecond rounding. Eligible native utterance duration 2 <= end-start <= 19.6 seconds. Speech support is [floor(start*16000), ceil(end*16000)), all frames. Reject if support extends outside the file or exceeds 320000 frames. Padding is exactly ZERO frames: no acoustic or annotation-only claim of verified silence is made. Zero is within the permitted maximum 0.2 seconds per side; retain complete utterance with conservative outward rounding. Any outward rounding is below one frame per side, not deliberate silence padding. Reject if the frame support intersects any other nonempty annotated interval, including same-speaker labels; thus no labeled utterance is cut, including boundaries affected by rounding. This is annotation-based nonoverlap only, not proof of inaudible cross-talk. Every nonempty native tier interval is protected. Blank intervals are not speech. A nonempty reference must remain nonempty under the existing score_predictions.py normalization. No speaker inference. Tier names are gold labels.

RMS: read only eligible utterance's channel-0 frames in <=4096-frame blocks. Compute exact integer sum(sample^2) and divide by frame count. RMS rank uses exact rational mean-square, tie-broken by utterance deterministic ID. No gain or relative normalization. Within each meeting's complete eligible candidate pool, sort ascending by (exact mean square, ID). q1=floor(N/4), q3=floor(3N/4). Quiet rank [0,q1); ordinary rank [q1,q3); upper quartile excluded from selection. This rank-based quartile definition is deterministic even at ties. Quiet is a loudness proxy, not proof of microphone distance.

ID: SHA256 of compact UTF-8 JSON array [session WAV stem, exact native tier name, original start timestamp string, original end timestamp string], ensure_ascii=False, separators=(',',':'). Duplicate IDs abort.

Speaker balance: for each meeting select quiet first then ordinary. At each of 4 selections for a stratum, choose candidate minimizing (speaker's already-selected count across both strata, speaker's already-selected count in this stratum, candidate SHA256 ID). This is deterministic greedy speaker balancing subject to available candidates. Selected supports must be disjoint. If fewer candidates exist, select what exists and report shortage, never widen rules.

Reference: preserve exact native text separately and retain trimmed annotation text as the comparison reference, following author convention. Keep native TextGrid bytes and SHA256. Freeze full candidate/exclusion inventory, ranks, selected IDs/frames, PCM/WAV/reference hashes, totals, code and source-runtime receipts before any prediction. Apply existing dev12-public score_predictions.lexical CER: NFKC, lowercase, remove Unicode P/S categories, remove whitespace for character edit distance. Later report micro CER (sum errors / sum reference chars), paired utterance outcomes and meeting/stratum breakdown. No claim of Chinese+English coverage from this Mandarin sample; no predicted word times or identity accuracy.


Both recognizers receive the same original-amplitude channel-0 PCM. Both use automatic language identification, with no reference, prompt, hotword, speaker, or transcript history.
