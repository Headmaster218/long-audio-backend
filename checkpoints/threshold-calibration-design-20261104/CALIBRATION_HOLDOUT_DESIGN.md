# 512D ERes2Net：独立校准与完全独立留出设计

日期：2026-11-04 UTC。状态：**仅设计，尚未选取新音频、拟合门槛、运行推理或修改产品。**

## 1. 本次应作的决定

保留前处理负结果和生产现状。下一步若获准，只研究一个很窄的问题：**固定 native 512D 模型、固定两秒单人语音、每人一个两秒参考、固定图库大小和 0.10 rival margin 时，能否在新的校准数据上选出一个有用的接受门槛，再在完全未用于选择的留出数据上估计错误与拒识？**

这不是会议自动识人的总体验收。手工确认纯净片段的误接受率不能移植到自动 VAD/diarization/选段、混音或跨段身份维护。实际 pipeline 的 crop 污染、漏检/混人、持续误认、错误传播和长录音稳定性仍需以后单独验证；本设计不顺带启动这些实验。

当前证据必须原样保留：

- [固定前处理结果](../frontend-compatibility-research-20261104/RESULT_REPORT.md)：18/18 已知 query 排名正确，但 18 个全部拒识；6 个未知 query 也全部拒识。零发出使已知召回与覆盖率为零，发出精度无定义。它没有证明低误接受率，也不授权降低门槛。
- 当前 [verified policy](../backend-capacity-source-20261031/source/audio_backend/profiles/verified-review-experimental-v1.json) 是 single=centroid=0.75、margin=0.10、最短注册/查询各两秒。[门槛来源审计](THRESHOLD_ORIGIN.md) 确认源码明确称其为 tiny-sample heuristic / 未校准实验策略，原始选择样本、拟合目标和风险依据未恢复。另一份旧 AMI20 legacy profile 的 0.55/0.56/0.10 不同策略存在会话重叠及失败记录；dev60 的 0.55 recording-local complete-link 又是另一决策过程。两者都不能替这个 0.75 身份匹配策略提供可移植校准。
- [训练分布审计](TRAINING_DISTRIBUTION_EVIDENCE.md) 未获得精确权重的训练样本清单。历史 recipe、模型家族标签和论文语料统计不能证明本权重实际训练分布或测试身份未入训。

**没有一项低误接受风险是通用默认值。** 未确定下面的目标和数据来源之前，本文件只是一份可执行化的研究设计，不能签发统计验收或启动生产修改。

## 2. 执行前仅需确认的范围

操作者需要确定：

1. **错误预算与单位。** 未知人被接受为任意已知人的最大容许概率 `r_U`；已知人被发成另一人的最大容许概率 `r_W`；是按一次 query、一个人/会话，还是一场会议衡量。若业务要控制整场会议出现一次错误的概率，不能用单 query 风险替代。
2. **有用性。** 最低正确接受率 `r_C` 或最高已知拒识率，以及容许的推理不可用率。否则“全部拒识”会轻易满足错误数条件，却没有实际用途。
3. **图库。** 实际要支持的固定人数 `K`，以及只认证一个固定图库，还是希望覆盖新用户各自建立的图库。`K` 改变 max-score 与 runner-up 分布；六人图库的结果不能直接推广到百人图库。本轮每人仅一个参考，不校准 centroid/多参考策略。
4. **目标数据与权限。** 是否能够提供/授权使用新的中文自然对话或会议录音，以及需要覆盖的普通话/方言、近远场、设备、房间和噪声范围。若只有英语朗读，结论就只能写英语朗读。数据来源与许可需核实；涉及未授权私人录音、外包标注或向第三方共享时，须先取得相应授权。公开许可数据的云端只读准备无需额外生产变更授权，但实际试验仍须先冻结方案与执行预算。
5. **统计置信要求。** 报告可采用双侧 95% 描述区间；安全验收通常使用单侧上界。若多个错误率/域都要同时合格，先分配总显著性水平，不能把每项单独 95% 当作整体 95%。

保留空缺而不是替操作者填入“安全 FAR”。这五项可以在一份简短的试验登记中集中确定，无需新评估平台。

## 3. 数据划分与泄漏排除

### 3.1 三种用途，不重新命名旧数据

- **D：已暴露开发/诊断数据。** 包含本次 LibriSpeech 的 8 人、全部参考与 24 queries，以及本项目已使用的 AMI、AliMeeting、AISHELL、Oyez 等数据、先前校准/筛选/确认/失败尝试与其派生片段。D 只用于解释旧结果和测试评估代码，不能再充当新 C 或最终 T。当前设计不从这些已接触语料中寻找“换一章/换一段就未使用”的最终留出。
- **C：新的校准集合。** 仅用于选择一个 scalar threshold。C 的已知人、未知人、注册音频、查询音频和录制来源在第一次看模型分数前固定。
- **T：完全独立、一次开封的留出集合。** 与 D、C 在真实身份、会话、源录音及派生数据上分离。T 不能参与阈值、前处理、margin、时长、参考选择、质量门、验收标准或样本量的选择。

`speakers(D) ∩ speakers(C) = speakers(D) ∩ speakers(T) = speakers(C) ∩ speakers(T) = ∅` 是要求，不是仅靠文件名即可确认的事实。未知身份或跨语料身份映射不明必须记录，不能把“没有查到重复”写成“证明绝无重复”。

### 3.2 按真实来源分组后划分

建立小型 manifest，记录匿名 speaker ID、原始会话/录音 ID、语料版本、站点/房间、采集日期、物理设备/声道、语言、内容/章节来源、原始文件摘要、时间区间及派生关系。先建立泄漏组，再一次性分配 C/T；不按 pair、短 crop、声道或增强版本随机切分。

- 同一人所有别名、所有章节、所有设备录音只能在同一集合；同一发声的同步多设备记录、重采样、副本、重叠裁剪都归为同一来源组。
- 同一原始会议的所有参与人、全部声道和所有 crop 不跨 C/T。多人共享会议会产生会话层依赖，需要在区间估计中保留。
- 每位已知人允许注册与 query 同身份，这是任务定义；但两者必须来自不同原始会话/录制事件，不能仅从同一文件隔开几秒。一本书的不同章节不自动等于不同录制会话。
- 朗读备选数据还应排除跨集合的同一本书/章节/同一脚本来源，或明确这是未满足的内容独立性；不能只看 utterance ID。自然会议不要求不同人从不说相同常用词，但不得复用同一发声内容的派生音频。
- 每套图库只包含该集合的已知人。该集合的未知人不能出现在其任何参考、备用参考或校准后的增补图库中。C 的未知人也不能转为 T 的已知人。

### 3.3 说话人分离之外，保留域分离

以“采集站点/房间 + 物理设备/通道链 + 采集批次”定义细粒度 domain/source bundle，C 与 T 不共用 bundle。T 内预先标出：

- **目标条件层**：仍为操作者指定的中文对话/会议条件，但人员、会话、场地或设备实例/批次未见于 C。
- **域外压力层（如有数据）**：预先保留一种 C 未覆盖的设备型号、远场条件或采集站点；单独报告，不能用它挑门槛，也不能用目标层的好结果掩盖压力层失败。

两层只是同一固定留出中的报告分层，不要求立即再建多个研究项目。若只有一个新域，就只认证该域并明确缺少跨域证据；没有必要为了形式做一个极小而无法解释的额外分层。更大的设备/语言/场景跨度不是“随机切分”能够证明的。

### 3.4 模型训练重叠单列为未知

项目内未使用与模型训练未见过是两回事。优先使用模型字节已冻结之后新采集、来源清楚且合法授权的录音；这能排除这些**新录音波形**曾进入已冻结权重训练，不自动证明同一人的其他历史录音未入训。记录可核验的训练身份排除信息；缺少完整训练清单时，报告仍须写“训练身份重叠未知”。不要拿官方 test split 标签或新语料名称替代证明。

## 4. 最小研究匹配契约

本轮只冻结下列单一策略，不复测已失败的候选前处理，不换模型：

- 模型：native ERes2Net 512D，ONNX SHA-256 `1a331345f04805badbb495c775a6ddffcdd1a732567d5ec8b3d5749e3c7a5e4b`；固定原生 Sherpa/ORT、输入处理和归一化，沿用已审计的 `snip_edges=False`、`high_freq=-400`。来源是 [embedding-space 审计](../backend-capacity-source-20261031/source/docs/EMBEDDING_SPACE_PROVENANCE.md)。执行前还须核实实际字节，而非只认文件名。
- 每个图库固定 `K >= 2` 个不同真实的人，各一个两秒参考；query 也是固定两秒。`K=1` 没有真实 runner-up，不纳入这轮 margin 策略资格。
- 两秒 crop 规则在看分数前决定；人工纯净度/身份核验不得看匹配分数。若使用人工确认纯净片段，该事实直接写入资格范围。不能按得分反复裁剪、选择最佳参考或重录直到通过。
- query 与其真实参考来自不同会话。参考选择按预先确定的录制顺序/随机种子，不能选择最容易匹配的那一个。注册失败是已计划图库构建失败，不能静默删除该人或临时缩小 K。
- 对完整图库计算同一套归一化 cosine，保留全部竞争者。按现有代码确定 winner、tie handling 和精确比较规则。接受条件是 `best >= t` 且 `best - second >= 0.10`，否则拒识；实际代码其他完整性/时长拒绝仍保留。
- 唯一可校准的变量是 `t`。0.75 是预先声明的基线。centroid、多参考投票、改 margin、score normalization、质量门、学到的概率校准器、模型/前处理比较均不放进这一最小轮次。
- 图库在整个测试中不变，不从 query 自学习、不自动建立新人、不把接受结果回灌参考、不 merge 身份。cosine 不是正确概率，0.75 也不是“75% 置信度”。

如果未来要改变两秒时长、参考数或自动 crop 规则，需要另一个明确的研究范围和新未暴露测试数据；不能把本轮门槛悄悄移植过去。

## 5. 评估单位、错误定义与完整分母

**基本决策单位是一条 query 对整个 K 人图库的最终输出**，不是 K 个 pair 分数。144 或 288 对相似度不能变成 144 或 288 次独立误接受试验。

预先区分已知 query（真实人已在图库）、未知 query（真实人不在图库）、参考真值不充分的 query，以及基础设施/推理不可用。单条有充分真值的 query 结果分为：

| 真值 | 输出 | 计数/含义 |
|---|---|---|
| 已知 | 正确的人 | `C_K`，正确接受 |
| 已知 | 图库中另一个人 | `W_K`，已知人误认 |
| 已知 | 合法运行后不发出身份 | `R_K`，已知拒识；包括门槛、margin 或固定有效性规则拒绝 |
| 已知 | 未运行/失败/未得到可信最终决策 | `F_K`，不可用，不是成功拒识 |
| 未知 | 任意图库身份 | `A_U`，未知误接受 |
| 未知 | 合法运行后不发出身份 | `R_U`，未知正确拒识 |
| 未知 | 未运行/失败/未得到可信最终决策 | `F_U`，不可用，不是正确拒识 |

`N_K = C_K + W_K + R_K + F_K`，`N_U = A_U + R_U + F_U`。两者保留所有有充分真值的已计划 query，不因失败、难样本或不发出身份而缩小分母。另报所有已计划项 `N_all`，包括不可判定真值/重叠/标注缺口数量和原因。

必须报告：

- 未知误接受：`A_U/N_U`，同时列绝对计数；这是 open-set probe-to-gallery 风险，不是 pair-level FMR。
- 已知误认：`W_K/N_K`。另可报条件误认 `W_K/(C_K+W_K)`，但不可用条件指标替代主分母。
- 已知拒识：`R_K/N_K`；正确接受/召回：`C_K/N_K`；总体未正确接受：`1-C_K/N_K`，包含误认、拒识和不可用。
- 未知正确拒识 `R_U/N_U`、可用率以及每类拒绝原因，避免把静默故障当安全。
- 有可判真值的发出精度 `C_K/(C_K+W_K+A_U)`；分母为零写“未定义”，不能写 100%。精度依赖人为设置的已知/未知比例，不能直接当部署 precision。
- 若有 `F_K/F_U`，同时给相应错误率的未决范围：已知误认从 `W_K/N_K` 到 `(W_K+F_K)/N_K`，未知误接受从 `A_U/N_U` 到 `(A_U+F_U)/N_U`。这只是把未决全部视为错误的保守敏感性范围，**不是置信区间**；不能靠失败稀释风险。未解决失败导致安全资格 INCONCLUSIVE。
- 有真值不明的身份发出必须单列为“无法核实的发出”，不得算正确或零错误。纯净片段资格不因这些项被排除而升级为自动选段资格。

同一人多条 query 时同时报按 query 的 micro 结果与每人等权的 macro 结果；主要权重及分层权重事前固定。分域、语言/设备和图库分别展示，不能事后只展示表现好的层。

rank-1、genuine/impostor 分数分布、pair-level ROC/DET 可以帮助诊断，但不能替代这些固定工作点结果。EER 或 minDCF 不是操作者给定风险预算下的验收。跨录音身份合并/长期错误传播本轮没有执行，因此不报告“误合并率”。

## 6. C 的选择与 T 的一次性检验

### 校准阶段

先完成历史门槛/训练分布审计，确认第 2 节范围并冻结 C/T manifest，才可申请新的执行。以下是未来选择规则，不是本次已经拟合的门槛：

1. 对 C 计算固定分数一次；标签仅在 C 上用于研究。选择算法、允许门槛集合和 tie rule 在看 C 分数前登记。例如可用合法区间 `[0,1]` 的 0.01 等距网格，含 0.75；不要结果出来后增加精细网格或引入新变量。
2. 在操作者预定的 C 上经验错误约束/候选条件内，选正确接受率最高的 t；若并列，按预登记规则优先更高 t。若没有同时满足有用性条件的候选，结论是“没有可推进候选”，不能把全部拒识当成功。
3. **C 是选择用数据，其选中工作点的普通区间不能被当作选择后仍有效的安全证明。** 小 C 的零错误也不是风险达标。C 的作用是决定是否值得付出独立 T 的成本，最终风险主张只来自 T。
4. 在开封 T 前冻结一个候选 t、基线 0.75、代码/模型/前处理/图库规则、样本与分母、区间算法、风险目标、数据量、排除条件、结果判定和停止规则。保留 C 的全部失败与尝试。

### 留出阶段

- T 的原始录音/身份分配可由独立保管者准备；执行者只看到计算需要的匿名输入。若设计者已经看过身份/条件元数据，应如实声明，不声称完整人工双盲。
- 门槛冻结前不访问 T 的分数、错误数或内容驱动的成功样本挑选。全部计划预测（含不可用）封存后，再解封 T 的真值做一次汇总。
- 主验收只有一个事先选定候选。0.75 基线为预定的同 query 配对比较，不允许查看 T 后在二者中“择优上线”。候选失败不能改选刚好通过的备选。
- 可以对完全相同的已封存结果修复可证明的报表算术/代码错误，但保留原报表、修复理由和审计；不得重新选段或重做模型输出来改善结果。
- 若根据 T 的表现改 t、margin、crop、模型、参考或任何规则，该 T 立即成为开发资料；新候选需要全新的最终留出，而不是“再验证一次”。

## 7. 置信区间：先证明抽样单位，再选公式

### 7.1 不能把相关分数当独立样本

NIST 的说话人评估研究明确指出，同一说话人重复使用会引入依赖并影响误差估计；按依赖组进行 bootstrap 比把分数视为 i.i.d. 更符合问题。[NISTIR 7884](https://www.nist.gov/publications/significance-test-speaker-recognition-data-analysis-data-dependency)；[Wu 等，The Impact of Data Dependence on Speaker Recognition Evaluation](https://pmc.ncbi.nlm.nih.gov/articles/PMC5484007/)。这里不宣称下面的简化研究设计完整复现其特定 bootstrap 算法。

实际报告至少列：人数、原始会话数、图库数、依赖簇数、query 数和 pair 数。多个 crop/同一人/同一会议/同一参考的复用不增加独立人数。预先固定一条 primary query/人，其余重复 query 用于稳定性诊断，可以减少伪重复，但“一人一条”仍不能消除多人共用一个会议的会话依赖。

对重复 query 的一般率和基线差值，可以使用预登记的 cluster bootstrap：同一人全部 query 一起重采样；若人和会议交叉共享，按 speaker–session 连接成的依赖块整体采样，而不是假装简单嵌套。域内分层、固定已知/未知抽样结构；比较两个工作点时保持同一个块的配对。用事前固定的重复次数和种子，例如 5,000 次，给双侧 95% 描述区间。

这是近似抽样区间，不能修补只有很少独立会话/图库的设计。若连接图使整个测试只剩几个大块，应报告无法可靠估计总体区间并收窄结论，不在几百个 pair 上重新做一个漂亮的区间。一般 bootstrap 在零错误时会得到退化的 `[0,0]`，**该结果绝不能当作罕见错误的上界**。

### 7.2 固定图库条件风险与跨图库风险不同

- **固定图库条件结果**：图库及其参考视为固定；从明确目标总体独立抽取全新未知说话人/录制事件，每人一条预定 primary probe。若这个抽样过程确实支持独立同分布 Bernoulli 决策，可对该固定图库的未知误接受用精确二项式区间。共享固定图库本身不等于必须把所有 probe 合为一个样本，但结论明确以这个图库为条件。
- **跨图库总体结果**：若要覆盖任意新用户图库，必须有独立抽取的多套图库、不同注册人和来源；把所有图库的 query 一股脑 pooled 到二项式中不成立。可以按独立 gallery/episode 做块级分析。一个或两个图库只支持很有限的条件描述，不能宣称跨图库安全。
- 已知误认同样受到已知身份、注册参考和会话复用影响。若要对其使用严格独立 Bernoulli 资格试验，需要有可辩护的独立 enrollment/gallery/probe episode 抽样，或明确条件于固定图库的独立抽样模型。不能因为未知人试验满足独立条件，就自动给已知误认也套同一个 n。
- 一个独立会话/人的“三条 query 是否至少错一次”可作为块级二元终点；其区间描述的是**三条固定 query 的块级风险**，不能偷换成单 query 风险。若业务关心整场会议，应固定整个会议级机会数和评估流程以后再设计，而不是套当前公式。

### 7.3 零错误样本量只适用于真正的独立试次

采用单侧 `1-alpha` 精确二项式上界时，若 **n 个实际独立、符合声明抽样模型的试次**中零错误：

`U = 1 - alpha^(1/n)`。

若希望零错误时达到 `U <= r`，则 `n >= ceil(log(alpha)/log(1-r))`。这是从 `P(0 errors)=(1-p)^n` 直接求得；非零错误时使用二项分布反演/Clopper–Pearson 上界，不使用零错误公式或 Wald 的零宽区间。[NIST exact-binomial 说明](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbino.htm)。

以下仅示范规模，**不是建议的安全目标**。单项、单侧 95%、零错误时：

| 假设要证明的风险上界 | 至少需要的实际独立试次数 n |
|---|---:|
| 1% | 299 |
| 0.5% | 598 |
| 0.1% | 2,995 |
| 0.01% | 29,956 |

对 n=30、60、100，零错误的上界仍分别为约 9.50%、4.87%、2.95%。同一位未知人三个 crop 不是三位独立未知人；现有 6 条未知 query 来自两人，不能把它们直接当六次独立试验给正式风险界。

若两项风险须同时达到总体 95%，一种简单且事先可登记的方法是每项用 `alpha=0.025` 的 Bonferroni 分配；例如每项零错误证明 0.1% 时需各 3,688 个符合独立模型的试次。还要同时认证多个域时再分配，或提前限制唯一主资格域，其他域只作描述。

这些 n 是“零错误时可能通过”的下限，不是有足够检验功效的完整样本量计划。计划还要考虑预计真实错误率、允许的非零错误数和目标 power；未知真实率时不要承诺这个 n 一定足够。按 query 的近似 `n_eff` 或未经验证的 ICC 不能替代真实 n 来套精确二项式。

### 7.4 固定终点，不看到通过才停

预定最终 n/固定采集清单和一次主分析。不得每积累几十条就计算一次 95% 上界，然后在首次低于风险目标时宣布成功，也不得失败后继续追加到通过。若确需序贯试验，需要在采集前确定有效的 confidence sequence/alpha-spending 方案和最大预算；最小设计不引入这层复杂度。

完整性、资源或安全问题可以提前停止，但结果是 BLOCKED/INCONCLUSIVE 或预定 NO-GO，不是提前通过。任何新的扩充批次必须在未查看该批结果前重新登记推断规则；不能把旧的反复窥视当成一次固定样本试验。

## 8. 分阶段的最小可行规模

本次到设计为止。后续可先选择 **一次小型、无生产资格的 C/T 可行性试验**，而不是立即要求万人数据或建设新评估层。

一个便于估算工作量的例子（`K=10` 只是示例，必须由实际目标替换）：

| 集合 | 图库/域安排 | 已知人 | 未知人 | 每人 query |
|---|---|---:|---:|---:|
| C | 两个来源不共享的十人图库 | 20 | 40 | 1 条 primary + 2 条重复诊断 |
| T | 两个全新十人图库，可分别对应目标层和压力层 | 20 | 60 | 1 条 primary + 2 条重复诊断 |

合计 140 个真实不重复的人、40 条注册参考、420 条 query，共 460 个两秒 crop。只是 15 分 20 秒的裁剪输入量，不代表采集/标注仅需要这点录音或时间。已知人的注册与查询至少两个不同会话；来自同一会议的多人仍组成依赖块。预算重点是获得独立的人与录制事件，而不是制造更多 pair。

这个试验能发现“排序虽好但仍无覆盖”“明显误认”“某个域完全失败”以及协议/标注问题；不能证明千分之一量级风险。若 T 两层各 30 个未知 primary，即使各自满足独立模型并且零错误，单层单侧 95% 上界也仍约 9.50%；不能把不同域/图库的 60 人合并后悄悄缩窄资格范围。

若新中文数据不足，可以更小规模做诊断，但明确降为可行性观察；不要把图上平滑的曲线当统计资格。已有数据全部留作 D，不因数据不够而回填 C/T。

只有小试验显示存在有用候选、操作者仍需要风险资格、且新数据/预算可实现第 7 节所需独立单元时，才另行登记一批更大的**全新资格留出**。已经开封的小 T 不再为后续调整后的方案提供独立资格。若研究范围或数据足够明确，也可以跳过小 T、直接把唯一 T 设计为足量资格集合；不强制增加阶段。

## 9. 结果判定与停止边界

未来的唯一主结论按预登记条件写：

- **限定范围内通过统计条件**：完整性/可用性条件满足；各主错误率的有效单侧上界不超过操作者目标；正确接受的有效下界达到有用性底线；所有预声明必须通过的域都满足。仅能说该固定两秒、单参考、native512D、指定 K/图库和采集条件的研究策略满足这些条件。
- **NO-GO**：违反预定错误/有用性标准，或没有有用候选。保留前处理负结果与本轮负结果，不自动降阈值、换人、换 crop 或扩大样本到通过。
- **INCONCLUSIVE/BLOCKED**：区间太宽、独立单元太少、训练/数据来源不能达到所声称边界、真值/完整性不足、失败未解决或没有目标/数据授权。不把缺数据写成“安全”。

通过也不授权修改生产、迁移 embedding bank、降低既有组策略、自动关联真实身份、扩大到 centroid/多参考、中文所有方言、自动会议选段、长录音或持续身份状态机。是否进一步做实际 pipeline 和部署验证由操作者另行决定。

## 10. 最少应保存的文件

复用现有研究工具，只需小型本地研究记录：

1. `protocol.json`：范围、一个待选 t 的规则、最终冻结值、K、阈值/运行字节摘要、目标、区间/停止规则及授权范围。
2. `split_manifest.csv` 与密封真值：D 排除清单摘要，C/T 人/会话/域/来源绑定，固定注册/query 角色，预期独立/依赖块。真值和原始个人数据按现有权限保存，不把原始录音、身份向量或私人身份信息放进公共报告。
3. `predictions.csv`：每条计划 query 的完整 final status、匿名输出、score/margin、图库版本、失败原因与预测封存摘要；另存已声明的诊断 pair 分数即可。
4. 一份结果报告：计数、所有分母、域/图库/人/会话覆盖、所用区间及其假设、不可判定项、所有失败与停止原因、可主张和不可主张的边界。

不需要增加长期调度器、在线学习层、自动回灌、通用评估服务或新的产品表。当前文件是设计交付，**新音频/模型下载、数据选择、推理、阈值搜索、生产改动均为未执行**。
