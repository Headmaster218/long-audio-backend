# 单轮校准/留出 pilot：冻结协议候选

2026-11-04 UTC。版本：候选 v1，**数据元信息和执行清单填实后才能冻结**。本文件细化当前已获准的、资源合理的研究 pilot；不再以操作者先指定极低风险目标为前提。仅准备协议，本文件编写者未下载音频/模型、未推理、未拟合或修改产品。

## 目标与边界

只回答：新的 C 上能否选出一个非退化的 scalar threshold；同一个阈值在完全未用于选择的 T 上，其已知正确接受、误认、拒识与未知误接受各是多少，区间有多不确定。

固定 native 512D、两秒、每人一个参考、0.10 rival margin；比较候选和预定 0.75 基线。**本轮不是低风险认证，没有隐含 FAR 目标，不上线。** 本次 LibriSpeech 8 人/24 queries、所有原有 AMI/AliMeeting/AISHELL/Oyez 等项目已使用数据及其人物/同源派生录音仍只属开发诊断，不能进入新 C/T。

优先新的公开、可复现中文真实跨会话数据。若只能取得中文手机任务语音/朗读，就如实命名该场景，不声称会议或自动选段准确率。手工/标注确认的纯净两秒片段结果不能移植到自动 diarization、crop 污染、持续身份状态或长录音。未知原始训练重叠单列；新项目留出不等于模型训练未见过。

## 1. 只需在任何分数出现前填实这些参数

| 字段 | 冻结要求 |
|---|---|
| source | 官方语料版本、许可、URL、最小获取路径和摘要；不得为本轮强拉不合理的完整大包 |
| split | C/T 真实身份、原始会话/发声/文件来源不重叠；旧项目排除清单；固定选择种子与顺序 |
| K | C/T 各一个固定图库，人数相同；`2 <= K <= 10`，由真实跨会话可用身份数决定 |
| U_C, U_T | 各自未知人数，`2 <= U_C,U_T <= 20`；优先 T 不少于 C；如数量更少，只能进一步缩为诊断，须先改协议再冻结 |
| R | 每人固定三条不同 query：第一条为 primary，其余两条为人内变化诊断。若数据只能支持一条，允许**冻结前统一改为 R=1**；不在结果后增删 |
| enrollment/query | 已知人的唯一注册与 query 来自不同真实录制事件；官方日期/会话字段作证，不能把同文件分段当跨会话 |
| crop | 两秒、固定位置规则、解码/声道/重采样规则；按元数据与预定纯净度/长度规则选片，绝不按模型分数选片 |
| domain | 语言、设备、距离/场景、是否同任务/脚本、C/T 细粒度来源分离情况与未知字段 |
| resources | 下载/解码读取量、墙钟/CPU/内存/磁盘上限、预计文件/编码数、原进程 wait/清理规则和真实可用空间 |

不得仅为了达到上表人数放松真实跨会话、身份不重叠或旧资料排除。使用官方 held-out split 可降低某些已知训练泄漏风险，但不证明未知权重训练清单不含它。若官方 test 规模不足，可事前选择其余合规新身份并明确限制，不能把“official train”隐藏成“训练未见”。

元数据决定取多少人，不由模型效果决定。选择规则优先使用匿名身份/来源连通块的单种子哈希排序；将共同人物或原始会话连接为不可拆分组后分配 C/T。先一次性记录可行名单、固定角色和具体录音，再开始 C 评分。没有足够跨会话证据则停在数据阻塞，不能以新的文件名替代。

## 2. 极小数据布局

- C：K 位已知人构成固定图库，每人一个参考及 R 条 query；U_C 位未知人只有 R 条 query。
- T：完全不同的 K 位已知人及 U_T 位未知人，完全不同的会话/原始录音，结构相同。C 的未知人也不能变成 T 的已知人。
- 同一人 R 条 query 中的 primary 在任何分数前固定；重复诊断项不进入选阈值或主区间的 n。它们全部保留并报告，不能只展示 primary 的好结果。
- 同一发声的同步设备/声道、副本、增强、重采样、重叠 crop 算同源。已知人的两秒参考不得与 query 共享发声。若不同章节/文件缺少独立录制事件证据，只能记录为“跨文件，跨会话未证实”。
- 同一原始会议若有人同时参与 C/T，则两套数据不合格。多人同一会议中的不同 probe 仍有会话依赖，供统计报告使用的依赖块也须记录。
- 相同粗粒度语料域可用于同分布 pilot，但不得声称“完全未见域”；只有实际元数据支持的站点/设备/批次分离才写域分离。无跨域证据不是更换元数据标签的理由，而是结论限制。

最大布局 `K=10, U_C=U_T=20, R=3`：60 个真实不同的人，20 个注册 crop、180 个 query，总 **200 次首次编码**；各 split 100 次。另允许共8次事前固定的相同输入重复编码作为确定性控制，C/T各4次，总上限208。四个样本ID及重复顺序、容差须在运行前冻结，重复输出不能替代原输出或增加统计n。实际可更小；若C无候选而终止，就不执行T或其重复控制。这个上限不是必须补足的配额，不准失败后自动重试。相同封存向量可同时算候选和基线，无需再次推理。

### 当前数据候选：SMIIP-TV（尚非冻结选择）

数据来源核查已确认官方58个eval身份及跨日字段，具体提案为 `official_eval_enroll_model.txt` 中前32个成年身份（元数据选取，无模型分数）。以固定seed `20261104` 对speaker ID做SHA-256排序，精确拼接和tie rule由同时冻结的manifest生成器规定；前16人为C、后16人为T，各自排序前6人为known，后10人为unknown。C/T各 `K=6, U=10, R=3`：12条参考+96条query，共108个不同crop，加上述8次控制最多116次编码。只用自由文本 `ti_0`，不用通常短于两秒的 `td` 唤醒词。C注册/查询日期为2020-05-01/05-08、05-15、05-22，T为2020-06-01/06-08、06-15、06-22。0508/0608是primary，后两日期为diagnostic。每日期slot最多3个事前固定、字典序排列的 `ti_0` 材料候补，仅按下面的无模型可用性规则选第一个合格者；须将最终108文件清单与生成器/筛选记录摘要一起冻结，不能只冻结人数。

该语料为中文手机任务语音，**不是会议**。日期字段有作者代码支持，但同一家庭/物理设备/采集站点映射缺失；无法证明与旧匿名语料的真实物理人绝无重合。只能分别报告“该语料内身份ID分离、不同原始录音/日期”“未发现已用项目来源重用”“跨语料真实身份/家庭/设备/训练重叠未知”，不得将这些合写成无条件的全球身份/域独立证明。

首个已检查WAV为16kHz/PCM16/双声道。材料可用性要求是16kHz、PCM16、双声道、至少两秒、文件不超过1MiB；在该slot的最多3个固定候补中选字典序首个合格者，记录每个拒绝原因。不以声音内容、能量、语音比例或模型分数选取。所有更靠前候补必须已经取得明确不合格结论，不能因尚未读到就跳过；达到获取上限仍有未决或该slot无合格者即BLOCKED。仅这一事前规则可在最终样本冻结前选材料，最终108crop封存后不再替换。

固定取channel0、中央32000frames（start=`floor((N-32000)/2)`），不补零、不按得分/听感换声道或裁剪。作者speaker标签不是对每个中央crop的人工纯净度认证，报告须保留该限制。上述3候补规则是模型分数出现前明确修订的材料可用性规则，原“只取首项、失败即停”的未执行提案不应被记成已经发生的实验失败。

完整gzip约49.95GB，不为这个pilot自动拉全包。准备阶段须另行冻结流式读取的字节/时间上限，只留预定成员；达到上限仍未齐全即BLOCKED。不能以边读边看到可用身份的顺序重新挑一个成功子集；若要改样本方案，须在模型分数完全未暴露时明确更新准备协议和记录原因。

### 分开的资源预算

- **元数据/模型自由准备**：固定元数据清单、最多324个WAV候补的成员列表、纯计算测试和最终108crop封存。没有模型调用。其具体耗时/输出另记，不冒称包含在模型阶段的测量中。
- **材料获取**：压缩网络字节总上限8GiB，流式处理，不保留完整49.95GB archive；只保留固定候补/最终所需的小WAV及有界记录。准备器另行冻结墙钟、CPU、内存、解压读取量、保留文件总量和清理上限；这些未填齐前不能认为仅8GiB网络上限已足够放行。达到上限不自动追加。
- **模型C**：最多54个不同crop+4个固定重复控制=58次编码；900秒wall、600秒CPU、3GiB sampled RSS、32MiB输出。
- **模型T**：只有候选锁成立后执行；同样最多58次，900秒wall、600秒CPU、3GiB sampled RSS、32MiB输出。
- C/T严格串行，不同时驻留两套模型进程；合计模型阶段最多116次、1800秒wall、1200秒CPU、64MiB输出。实际预期远低于上限，但上限不是估计耗时或提前通过依据。sampled RSS不是连续内核强制峰值保证；原进程持有、退出码、positive wait和清理证据沿用受审查的runner约束。

上述是为**本轮**明确确定的有限预算，不把前一次frontend实验预算自动扩展或续期。下载准备和两次模型阶段的计量范围分别报告。

## 3. 不变的预测契约

- ONNX SHA-256：`1a331345f04805badbb495c775a6ddffcdd1a732567d5ec8b3d5749e3c7a5e4b`，native ERes2Net 512D。复用实际审计过的 Sherpa/ORT/KNF 和原生 normalize、`snip_edges=False`、`high_freq=-400`；冻结实际字节、线程和输入处理，不只填模型名。
- 图库每个身份仅一条参考；全部 K 个真实竞争者都参与。query 对图库输出一个 person 或拒识。沿用现有精确算术、tie rule、完整性门和顺序；接受当且仅当 `best >= t` 且 `best-second >= 0.10`，并满足其余固定有效性条件。
- 不修改 margin、时长、参考数、centroid、score normalization、质量门、模型、前处理或图库。不得从 query 学习/补参考、自动新建人物或 merge。cosine 不是概率。
- 注册或 query 必需预测失败/不可用时，保留计划项和失败，停止依赖阶段；不能悄悄减少 K、换人或换 crop。

## 4. C 选择算法：一次、单变量、明确退化停止

事前固定候选集合 `t = i/100, i=0,...,100`，包含基线0.75。不加结果驱动的细网格。

1. C 的全部已计划输出完成并封存后，才能用 C 标签。人/条件元数据可供事前选样，不声称完整人工盲测；选样和标注人员不能看到模型分数来挑样本。
2. 每个 t 在 **C primary queries** 上计算已知正确 `C_K`、已知错人 `W_K`、未知接受 `A_U`。
3. 候选可行条件：`W_K=0` 且 `A_U=0`，且全部要求的输出/图库有效、无未解决不可用项。这个条件只是经验选取法，**不是风险保证或安全通过**。
4. 在可行 t 中先最大化 primary `C_K`，并列选更高 t。只输出一个候选。重复诊断误认/接受另外完整报告，但不事后改变这个选取算法。
5. 没有可行 t，或最大 `C_K=0`，则记 `NO_USEFUL_CANDIDATE`，结束本轮校准，**保留 T 未开封**。不把全部拒识当推进理由，不临时调 margin 或扩大网格。
6. 选到候选后，写不可覆写的候选锁：完整协议/样本 manifest/代码/模型/运行配置摘要、C 输出摘要、候选 t、C 主/诊断计数、0.75 基线、下一步唯一 T 清单。锁落盘并核验后才可访问 T 模型分数。

C 是选择数据，其错误/区间不得作为选中门槛独立有效的准确率证据。本轮不拟合概率校准器，不根据 C 的零错误声称低 FAR。

## 5. T 一次检验

候选锁之后按固定清单编码 T 一次。候选和0.75共用完全相同的分数/图库/失败信息；封存全部已计划预测后才进行 T 标签汇总。若文件名/设计元数据已有身份信息，明确暴露范围，不谎称人工双盲。

主报告是预先选定候选的结果；0.75 是配对描述基线。不能看 T 后在二者间挑一个“上线门槛”，不能把 T 误差用于调整 t。任何结果驱动的规则变更都使 T 变成开发数据；不在本轮再启新留出。

固定样本终点、一次主分析。不得边看错误数边追加，不得在区间首次达到某值时停，也不因结果不理想补样到通过。完整性/资源问题可提前停止，状态是 `BLOCKED/INCONCLUSIVE`，不是安全成功。可对封存输出修复可证明的报告算术错误，但保留原报表/修复记录，不能因此重录或重推理。

## 6. 主计数与分母

基本单位：**一条 primary query 对整套固定 K 人图库的最终决定**。每人一条 primary 不自动保证不同人共享会议时的独立性。

- 已知：正确 `C_K`、错人 `W_K`、合法拒识 `R_K`、不可用 `F_K`；`N_K=C_K+W_K+R_K+F_K`。
- 未知：接受任意已知身份 `A_U`、合法拒识 `R_U`、不可用 `F_U`；`N_U=A_U+R_U+F_U`。
- 报 `C_K/N_K`、`W_K/N_K`、`R_K/N_K`、`A_U/N_U`、`R_U/N_U`、不可用率，以及所有整数分子/分母。
- 发出精度 `C_K/(C_K+W_K+A_U)` 分母为零时写未定义；它依赖本试验已知/未知比例，不等于部署精度。
- 真值不充分、重叠/标注缺口、无法核实的身份发出单列，不按零错误处理；全部已计划数仍须可核对。不可用也不是成功拒识；有 F 时列观测错误到“所有未决都错”的敏感性范围，明确这不是置信区间。
- 全部 R 条 query 的 micro/macro、人内变化、rank-1 和分数分布只作预定诊断；另表展示，不与 primary n 混用。在当前K6/U10提案中，主表是6 known/10 unknown；含primary在内的全R=3诊断表是18/30；若单列两条extra-only，则是12/20。K个pair、不同比较阈值和重复query不是新增独立试次。

## 7. 本轮统计政策与最小实现

不新增依赖服务。scorer 使用标准库/已有可信数值库即可；模型自由测试覆盖极端值、失败和分母，不运行声学模型。

**本轮已在任何模型分数前明确采用以下具体口径：正式总体/安全资格CI一律为null，原因是当前来源不能确证iid；仅T另列“独立同分布二项模型假设下的参考区间”。这一口径必须写入最终协议、候选锁和结果报告，不能看到结果后选择是否披露。**

1. **正式区间字段**：`population_ci=null`、`safety_qualification_ci=null`，并保存 `reason=independence_and_population_sampling_not_established`。主表始终保留真实T primary计数6/10。C选中门槛不附独立有效性CI；参考区间也不用于C选取。
2. **T模型参考区间**：只在T计划输出/真值完整时，对 primary正确接受、错人、拒识、未知接受/拒识各自的二元比例显式调用Clopper–Pearson函数。使用双侧95%参考区间，并可另列错误率单侧95%参考上界，标明两者区别；已知类n=6、未知类n=10。字段/标题标为 `conditional_iid_model_reference`，条件是固定图库、现有域、假设独立同分布Bernoulli采样。零错误单侧参考上界为 `1-0.05^(1/n)`。不对发出精度、整体混合覆盖率或配对差值硬套一个二项n。T有未解决不可用/真值不足时，参考区间也为null，报告原因。
3. **假设不等于证据**：SMIIP-TV虽有不同身份、各自手机和跨日期原始记录，但家庭/设备/采集关联缺失，不能写成已证明的独立性。固定6位已知人的误认/拒识概率也可能不同，hash分人、一人一个primary不证明iid。参考区间只用来显示在简化假设下小样本仍有多大不确定性；不是总体覆盖保证、经验安全界、跨图库资格或晋级门槛。二项公式的exact只指该假设模型下的算法，不代表抽样假设已验证；各项95%也不声称联合95%。
4. **重复/相关数据**：额外query只报计数、人内变化和speaker/session数，不把它们当独立n。最小helper本轮不新增bootstrap层，不承诺已实现cluster CI。不能靠普通bootstrap在零错误时得到的 `[0,0]` 宣称零风险。
5. **不能自动替换 n**：不得把 pair、重复 crop、重复编码或估计的 effective n 填进 exact-binomial 公式。若另报告“一个人/会话的 R 条中是否至少错一次”，明确那是块级终点，不是单 query 风险；本轮不另配区间。
6. **配对差值**：候选相对基线的正确接受/拒识/错误变化在同一 T primary query 上配对报告整数与比例；本最小轮次不强加不可靠的差值CI或显著性筛选。它不改变候选，不作为风险合格阈值。只有一个T图库，不推断任意新图库的安全性。

建议区间输出统一带 `method, status, confidence, sides, lower, upper, unit, n_units, assumptions, conditioned_gallery`。无法支持独立模型时显式 unavailable 比一个错误精确数字更可信。区间可从[NIST binomial定义](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbino.htm)核对；依赖警告依据[NIST speaker evaluation依赖研究](https://www.nist.gov/publications/significance-test-speaker-recognition-data-analysis-data-dependency)，本最小helper不复现其bootstrap算法。

## 8. 有限结果与交付

可能终态只有：`NO_USEFUL_CANDIDATE`（T仍密封）、`PILOT_COMPLETE`（候选/基线计数与区间/区间限制完整）、`BLOCKED/INCONCLUSIVE`（数据、推理、完整性或抽样不足）。**不设置“安全PASS”或生产晋级状态。** 没有CI或宽CI不触发自动扩样；出现错误也不触发改阈值。

最少保存四类文件：冻结协议和数据manifest；C封存输出及候选锁；T封存预测和一次汇总；简短报告及资源/清理收据。原始音频、身份向量和未授权个人身份资料不进公共Git。已有完整设计中的更大样本风险资格方案仅作为未来参考，不是本轮需要启动的工作。
