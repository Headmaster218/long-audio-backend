## Product and deployment changes

The dev69 checkpoint adds opt-in bounded retries for precisely typed busy recorder
GETs and a constructor-free advisory voice-embedding diagnostic. Writes, uncertain
responses and arbitrary 503s do not gain automatic retries. ASR remains usable
when optional embedding preflight is unsupported. No acoustic allowlist, model,
threshold, crop cadence or sample-selection policy was changed.

A fresh same-host CPython 3.12.14 / SQLite 3.53.1 runtime matches all eight audited
embedding artifacts. Four CP312 wheels are explicit restorations of verified
installed bytes; this is not freshly established official-wheel provenance or a
general installation solution for other servers. A fresh physical SQLite probe,
independent audit and nine candidate checks preceded narrow materialization.
Only the two reviewed target qualification literals were materialized. The full
wheel contains 184 package files; installed verification covered 4,305,639 bytes.
All 32 dependency versions stayed fixed. No bytecode remained.

The final selected regression passed 771 cases, zero failures/errors/skips.
An earlier validation attempt had 770 passes and one test-launcher failure: its
child lacked the test-tool import path. The launcher also omitted child bytecode
suppression. That failed log and the 98 generated cache hashes were preserved;
only generated caches were removed, exact source/dependency bytes reverified,
and the complete selected regression rerun. No product change hid those errors.

## One post-recovery exploratory comparison: negative result

The original interrupted study was not reclassified as successful. A new plan
was sealed before label access, explicitly identifying the recovered collection
and its limitations. Unchanged production bindings, exact source PCM/float
hashes and vector-BLOB validation passed for all eight saved observations; seven
were eligible and one remained excluded for its original packet-overlap witness.
This established only the frozen exploratory technical prerequisites, not
acoustic certification or production enrollment authority.

The original fixed sample, thresholds, reference-selection rules and scorer were
retained. All 23 existing controls passed. Exactly one replay sealed predictions
before reading query labels. There was no new inference, rescoring, automatic
enrollment, human-listening claim or favorable crop selection. All 456 pinned
original artifacts remained unchanged.

Both the empty-gallery baseline and carryover candidate yielded:
- Correct: 0/2 scorable queries.
- Wrong suggestions: 0/2 scorable queries.
- Abstained: 2/2 scorable and 3/3 natural queries.
- Missed identity for the person with a research reference: 1/1.
- False acceptance of the predefined withheld person: 0/1.
- One annotation-overlap query remained unscorable; it emitted no identity.
- Precision is undefined because there were no identity emissions.
- Actual false merges were not measured; no merges were performed.

The candidate similarity scores were 0.355302 for the annotation-overlap query,
0.420730 for the known reference person and 0.104341 for the withheld person, all
below the unchanged 0.75 threshold. This is not evidence that lowering the
threshold is safe. A one-person gallery cannot establish multi-person margins.

Adequacy failed: only one reference person, one scorable known-person query and
one represented known person, versus the frozen requirements of two, three and
two. Withheld coverage was 1/1. Verdict: INSUFFICIENT_EVIDENCE; no useful finite
carryover improvement established. Tiny observed zero-error counts are not proof
of low false-merge risk. This is dataset-reference exploration, not product voice
enrollment, transcript speaker relabeling or cross-boundary ASR improvement.
