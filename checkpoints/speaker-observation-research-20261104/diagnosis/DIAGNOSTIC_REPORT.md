# 已冻结中文跨日 pilot：失败机制的只读诊断

## 结论先行

**现有证据支持把“更可靠的语音观测与多参考”作为下一轮需验证的研究方向，但没有证明简单聚合有效，也没有把失败归因于切分。** 旧 T 集已被查看，不能再用来选择切分、清洗门槛、聚合方法或身份阈值。此次只解释原始分数和向量几何，不计算聚合后的 T 准确率，不修改任何原判定。

- 冻结结果仍是 T 已知人 4/12 正确、8/12 拒绝，未知人 0/15 接受。全部 8 次已知拒绝的最高分低于已冻结 0.46，其中 3 次的原始分差也低于 0.10。不存在遗漏输出或编码失败来解释这些拒绝。
- T 的 31 个输入 crop 及其源文件 channel 0 均无 PCM 极值样本，也无接近满幅的样本。这不支持“当前文件严重数字削波”作为普遍解释，但不能排除录制时已削波、限幅后降增益等历史失真。
- T 被拒的 8 个已知 query **并不更安静**：RMS 中位数 -25.77 dBFS，低能量帧比例中位数 0.5%；4 个正确 query 相应为 -30.08 dBFS、13%。正确结果中还包含最安静的 query（-43.70 dBFS，31% 低能量帧）。简单“音量低/静音多所以失败”的解释与本组描述性观测不符。
- 各人的几何模式不同：0085 的一次错排仍与其他同人 query 有中等相似度；0222 的 query 彼此比对单一 reference 略一致；0079 的额外 query 连彼此及 primary 都不一致。这些现象无法被“只要换掉一个坏 reference”统一解释。

## 方法与审计边界

读取原 `RESULT_REPORT.md`、`T_REPORT.json`、`C_SELECTION.json`、冻结 predictor/truth/manifest、sealed T 分数、保存的 normalized vectors、原 acquisition receipt 和其已保留 WAV。62 个 crop 全部按字节核对，确为源文件 channel 0 中心 32,000 个样本（2.000 秒），无重切片、增益、重采样、补齐或 VAD。源文件 channel 1 不参与分析，也不据此改变原输入。

波形指标：PCM16/32768；整段 RMS；20 ms 不重叠完整帧的 RMS；低能量代理为帧 RMS < -50 dBFS，另保留相对帧 RMS p95 低 30 dB 的代理；PCM 极值计数及幅值 >= 0.99 的比例。源文件与 crop 各自计算帧指标，源尾不足一帧时只在帧统计中排除。**这两个能量代理均不是 VAD、语音纯度、单人性或声学质量真值。** 指标是在原结果已可见后选定的描述性诊断，不是原先预注册规则，不做参数扫描或样本筛选。

保存向量按既有 float64 归一化/单参考余弦算法作校验。108 个 sealed T query-gallery 分数与原封存值逐项一致（最大绝对差 0）。新增的同 corpus speaker query-query 余弦仅供观察，不成为参考、不做新身份预测，也不计作独立样本。原 pilot 全部 89 个文件前后哈希不变，142 个实际读取文件均作前后校验，62 对源/crop 字节关系验证通过。

## 1. 源时长、中心 crop 与低能量

T 源时长范围 2.56–9.24 秒，输入一律只取 2 秒。T 已知拒绝 query 的源时长为 2.92–5.84 秒，crop 占原时长 34.2%–68.5%，保留源 channel-0 能量 31.3%–98.0%。正确 query 的相应范围为 2.56–9.24 秒、21.6%–78.1%、14.3%–98.4%。**保留的时长或总能量比例不能将成功与失败分开。** 不同源长度意味着固定中心 2 秒有可能丢掉有用内容，但未计算其他切片的 embedding，不能声称换切片会救回谁。

几个有区分度的反例：

| 已冻结 query | 原结果 / 真 reference 分数 | 源时长 | crop/源低能量帧比例 | crop 保留源能量 |
|---|---|---:|---:|---:|
| 0079 primary | 正确 / 0.594 | 9.24 s | 31.0% / 49.4% | 14.3% |
| 0205 extra-1 | 拒绝 / 0.449 | 5.84 s | 0.0% / 6.2% | 31.3% |
| 0205 extra-2 | 拒绝 / 0.166 | 2.92 s | 1.0% / 13.7% | 92.6% |
| 0222 extra-2 | 拒绝 / 0.422 | 2.92 s | 14.0% / 26.0% | 98.0% |

中心 crop 相比源文件常少含低能量区，但这不证明它含有足够的目标说话人语音。高能量可能来自目标人、其他人、背景声或失真；低能量也可能包含有效语音。C 的诊断数据单独保留，没有与 T 合并成性能或安全结论。所有 62 个 crop 均无极值样本；C 的源 channel 0 有两个极值样本，但没有进入任何 crop，因此不影响上述 T 结论。

## 2. 原始拒绝和同人向量几何

以下顺序均为 primary / extra-1 / extra-2。用 corpus speaker ID 作分组是原数据标签，不是听辨确认。

| T 人物 | 原真 reference 余弦 | 三组 query-query 余弦范围 | 解释边界 |
|---|---|---|---|
| 0205 | 0.622 / 0.449 / 0.166 | 0.252–0.454，均值 0.335 | 跨次差异明显；extra-2 不缺总能量但与 reference 弱匹配。不是单一静音解释。 |
| 0085 | 0.665 / 0.414 / 0.652 | 0.490–0.547，均值 0.521 | extra-1 错把 0079 排首（0.443；分差 0.029），被原规则拒绝。它与另两次同人 query 的相似度是 0.547/0.527，说明单次对单参考可能漏掉同人一致性；不能据此把 query 补入 reference 再报告提升。 |
| 0079 | 0.594 / 0.244 / 0.185 | 0.092–0.246，均值 0.160 | 不只 reference-query 低：primary 与两个 extra 仅 0.092/0.142，两个 extra 之间 0.246。单参考不足之外，内容、会话/通道、混音或模型变化都仍可能。 |
| 0222 | 0.313 / 0.375 / 0.422 | 0.408–0.532，均值 0.459 | query-query 均值高于 reference-query 均值 0.370，符合单参考代表性不足的可能，但幅度有限，也不是其唯一解释。 |

多次观测并不自动等于独立证据。这里同人不同日期的观测可共享设备、环境、内容习惯和系统误差；重复运行同一 crop 的逐字节一致 embedding 只证明重复性，不能增加身份支持票数。未知人的三个 query 也常表现出中等内部相似度（各人 query-query 均值 0.332–0.434），不得把“多条彼此接近”直接当作它属于已有 gallery 人物的证据。

## 3. 能支持什么，不能支持什么

**已观察到：** 固定中心 2 秒 + 单个跨日 reference 的匹配具有明显的人/会话差异；简单振幅、低能量或保留能量不能解释全部失败；部分人的跨 query 一致性存在，另一些则很弱。文件与保存分数的实现链一致，未发现错误 crop 或保存分数漂移。

**仍不可识别：** 单 reference 代表性不足、2 秒内容不足、目标 speaker 被混入/覆盖、环境或设备差异、模型域外弱点之间的因果贡献。没有人工听辨标签、纯净/重叠语音标签、VAD 真值、其他时段 embedding 或受控分离条件。来源中的环境自报、命名或 diarization metadata 只可作描述，不能证明 acoustic purity，更不能据此剔除失败样本。

**下一步的研究优先级：** 新冻结数据中先明确建立“目标单人语音/参考可靠性”的证据，控制总语音时长与观测次数，再比较单观测与多观测、单参考与多参考，固定聚合和拒绝规则。若还要比较切分，应在同一新方案中设独立、预先指定的切分条件，避免把“多取了语音”“换了时段”“用了更多参考”混成一个收益。选择规则仅可在新开发集上确定，然后一次评估新留出集。旧 T 只保留为本次诊断案例，不再参与选择、补参考、质量门槛调节或胜出方法挑选。

此次没有证明“聚合优于切分”或“切分有误”。更准确的判断是：**值得研究干净的多观测/多参考，但干净性尚无证据，聚合收益尚未测定，切分作为原因也尚未识别。** 生产 0.75/0.10、模型、前端、身份库和原试验判定均不应因这份诊断改变。
